# Sales Performance Analysis Dashboard

## Overview
An end-to-end practice project analysing sales, costs, profit, product performance, and city-level trends using Excel, PostgreSQL, and Power BI.

## Tools
- **Excel:** Data checks, profit calculation, and profit-margin calculation
- **PostgreSQL:** Aggregations, grouping, sorting, and business queries
- **Power BI:** KPI cards, city and category charts, and an interactive city slicer

## Key Findings
- **Highest-sales city:** Noida — 260,600
- **Highest-sales category:** Electronics — 424,050
- **Top product by sales:** Laptop — 285,000
- **Electronics profit:** 113,000
- **Furniture profit:** 41,600

## Business Questions
1. Which city generates the highest sales?
2. Which product category generates the most sales and profit?
3. Which products generate the highest sales?
4. How can city filters help explore performance?

## Files
- `sales_performance_dataset.xlsx` — practice dataset
- `load_sales_data.sql` — SQL data loading and analysis script, if included
- `Sales_Performance_Dashboard.pbix` — Power BI dashboard

## Note
This project uses a practice dataset. The findings describe the sample data and do not represent a real company's performance.
